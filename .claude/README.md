# Claude AI Agent System for Auto-OSBC

This directory contains specialized skills, commands, and agent personas for developing game automation bots with human-like behavior.

## Structure

- **skills/** - Reusable instruction sets for specific tasks
- **commands/** - Quick reference workflows and shortcuts
- **agents/** - Specialized AI personas for different development contexts

## Usage

Files in this directory are automatically loaded as context. Reference them naturally:
- "Use the human-behavior skill to add randomness"
- "Follow the bot-creation agent workflow"
- "Run the debug command for visual issues"

## Priority: Human-Like Behavior

All bot development must prioritize:
1. Randomized timing (no fixed delays)
2. Natural mouse movements (curves, overshoots)
3. Varied patterns (no repeated sequences)
4. Realistic decision making (mistakes, distractions)
5. Anti-detection measures (input variation)
